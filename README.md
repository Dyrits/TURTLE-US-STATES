# TURTLE-US-STATES

## About The Project

An exploratory Python project with Turtle and Pandas: a very basic guessing game. Guess the 50 U.S. states and each correct answer is written on the map.

### Built With

- Python
- Turtle graphics
- Pandas

## Getting Started

### Prerequisites

- Python 3 with Tkinter (needed by Turtle)

```sh
pip install -r requirements.txt
```

### Running

```sh
python main.py
```

## Usage

Type a state name in the prompt. Type `Exit` to stop. State coordinates come from `states.data.csv` and the map from `states.image.gif`.
